# Application materials

Material for MSc/PhD applications and interviews, built from the FairPath results. Every number comes from `reports/`.

| File | Use it for |
|---|---|
| [one_page_summary.md](one_page_summary.md) | Attach to applications or send after a first call |
| [research_directions.md](research_directions.md) | Seeds for a statement of purpose or a research proposal |
| [interview_prep.md](interview_prep.md) | Design decisions in plain words and 20 likely questions |
| [slides_outline.md](slides_outline.md) | Speaker notes for a 10-minute talk |
| [poster_layout.md](poster_layout.md) | A0 poster plan for a student research day |
| [demo_video_script.md](demo_video_script.md) | A 2–3 minute screen recording of the dashboard |
| [cold_email_template.md](cold_email_template.md) | First email to a prospective supervisor |
